# R Programming Portfolio

A growing collection of my R programming projects, coursework, data analysis exercises, and exploratory data analysis (EDA).

This repository is organized so that each project has its own folder, source files, datasets (where sharing is permitted), outputs, and project-specific README.

## Projects

| Project | Description | Folder |

1.  Student Marks Analysis | Processes student assessment marks, calculates totals and percentages, assigns grades, and exports results. |
2.  EuroEnergy EDA | Exploratory analysis of the EuroEnergy dataset, including data inspection, summary statistics, and visualizations. |

More projects will be added to this repository over time.

## Tools and Technologies

- R
- RStudio
- Git
- GitHub
- CSV datasets and data visualization

The specific packages used may vary by project. Check each project's README or the package-loading section of its R script for project-specific requirements.

## How to Use This Repository

1. Open the folder of the project you want to explore.
2. Read that project's `README.md`.
3. Check the dataset and package requirements.
4. Open the `.R` script in RStudio.
5. Run the script from the project folder, following any project-specific instructions.

## Notes

- Project-specific instructions and results are documented in each folder's README.
- Input datasets and generated outputs are kept with their related project when appropriate.
- Large, private, licensed, or restricted datasets should not be uploaded unless redistribution is permitted.
- Do not commit passwords, API keys, personal information, or temporary files.
- Outputs should be reproducible by running the corresponding R script whenever possible.
