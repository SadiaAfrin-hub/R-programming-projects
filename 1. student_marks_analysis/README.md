# Student Marks Analysis

## Overview
This project uses R to analyze student assessment marks, calculate total marks and percentages, assign grades, and export the processed results.

## Dataset
**File:** `students.csv`

The dataset contains student assessment marks. The script reads this CSV file from the project folder.

## Project Files
- `mini_project.R` — R script for importing, inspecting, processing, and summarizing student marks.
- `students.csv` — input dataset.
- `final_results.csv` — processed output generated by the script.
- `output1.png` to `output6.png` — saved output images.

## Tools Used
- R
- RStudio (recommended)
- CSV files

## How to Run
1. Download or clone this repository.
2. Open the `Mini-Project-Student-Marks` folder in RStudio.
3. Make sure `mini_project.R` and `students.csv` are in the same folder.
4. Run the script.
5. The script should generate or update `final_results.csv`.

## Analysis Workflow
1. Import the student dataset.
2. Inspect the data using functions such as `head()`, `str()`, and `summary()`.
3. Calculate total marks.
4. Calculate percentages.
5. Assign grades based on the grading criteria.
6. Summarize and export the processed results.

## Important Note
Check the maximum possible marks before calculating percentages. If the assessment components have maximum marks of 10, 20, and 40, the total maximum is 70. In that case, use 70 as the percentage denominator. Confirm the grading criteria before finalizing the output.

## Output
The processed student results are saved in `final_results.csv`. The output images provide visual or console-result evidence from the analysis.
