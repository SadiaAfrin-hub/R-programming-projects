# EuroEnergy Exploratory Data Analysis (EDA)

## Overview
This project focuses on exploratory data analysis (EDA) of the EuroEnergy dataset using R. The aim is to inspect the dataset, understand its variables, examine data quality, and explore relationships between energy-related measures and GDP.

## Dataset
**File:** `EuroEnergy.csv`

The CSV file is the source dataset used for the analysis.

## Project Files
- `EDA_report.R` — R script for the exploratory data analysis.
- `EuroEnergy.csv` — input dataset.
- `output_1.png` to `output_18.png` — saved output images.

## Tools Used
- R
- RStudio (recommended)
- CSV files

## How to Run
1. Download or clone this repository.
2. Open the `EDA-Report-EuroEnergy` folder in RStudio.
3. Make sure `EDA_report.R` and `EuroEnergy.csv` are in the same folder.
4. Run the R script.
5. Save any new plots or results in this project folder.

## Suggested Analysis Workflow
- Import and inspect the dataset.
- Review column names and data types.
- Generate summary statistics.
- Check for missing values and unusual observations.
- Explore relationships between GDP and energy variables.
- Create appropriate visualizations.
- Write short interpretations of the findings.
